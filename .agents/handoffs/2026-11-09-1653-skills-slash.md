## Decisions

- Skills reach the harness as an appended pointer, not as native slash commands: it works for every provider and leaves CHG-0031's isolation intact. Owner chose the recommended defaults after the questions were interrupted; the owner has not confirmed them one by one.
- Sources are the spec's folders only; plugin skills (for example Claude Code plugins) are not listed.
- The highlight is a text overlay, not an atomic chip with an icon; the text stays a plain `/name`.
- Completion applies only to a `/` typed at the end of the text.
- Agent-facing prose says quest; contracts, persisted identifiers, and harness tool names keep "mission" (the handoff `2026-11-09-1342-guild-board.md` rule).
- Not recorded in the changelog or `documentation/capabilities/tool-and-skill-loading/specifications.md` yet.
