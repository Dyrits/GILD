## Decisions

- Instructions that stay the same go in the system prompt, and data that changes goes in the turn's message. This keeps Claude Code from restarting with a different prompt, which loses the cache and, on Fable 5.1, Opus 5.5, and Sonnet 5.5, the earlier thinking. Recorded in CHG-0057 and the comments in `threads.ts` and `claude.ts`.
- The journal, intel, and budget note is sent on every turn, even when it hasn't changed. This is simpler, but the conversation history grows with each turn; see Open questions.
- Two audit findings were left as they are: `open_thread`'s "Use it instead of subagents." and the `answer_prompt` tool being visible to the model. Both are low-confidence, and moving `answer_prompt` to its own MCP server would be a structural change.
