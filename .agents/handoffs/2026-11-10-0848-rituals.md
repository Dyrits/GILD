## Decisions

- Claude Code models are a fixed list of full identifiers; no dynamic list (the CLI cannot list models). "Default" is gone from every list; `default` stays only as a legacy stored value, shown as "Default model". Recorded in the provider-accounts specification and CHG-0097. Sonnet 5.5 as the starting model is the agent's choice, provisional.
- A Ritual is one quest; each run is a message to the quest's main thread (stored as an owner message, first line "Ritual · run by you" or "Ritual · scheduled 07:00"). Schedules are presets in local time, no cron. Missed runs (more than 5 minutes late) are skipped; Run now works at any time but is refused while the thread is Running, Awaiting word, Summons, or Stopped. Recorded in the [rituals specification](../../documentation/capabilities/rituals/specifications.md).
- Fallback is on a failed turn only; it is a handover (thread-handover) whose line says "Fell back to ..." with the failure's first line; the next run starts on the primary Companion again. The owner asked for it to be explicit, as Timon's idea; Timon's site documents no display for it, so the line is the agent's design.
- Deleting a Ritual keeps its quest. Under a reached budget a run waits in Summons as for any quest.
- The scheduler sleeps until the next due Ritual and wakes on any change (at least hourly). A 30-second tick made nine clock-moving tests time out.
- Pushing to `main` needs `git push --no-verify` past the guard; the owner approved each push in their message.
