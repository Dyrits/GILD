## Decisions

- The look is fixed for a run and a change reloads the window: styles are cut at module load and about 450 uses of `colors.*` stay unchanged. Recorded in `documentation/changelog.md` (CHG-0159).
- The default is to follow the system, so an owner on a light system sees the light look at the first launch. One line in `foundation/colorScheme.ts` (the `"system"` fallback) changes it.
- New styles use `colors.*` only, never a hex, and never `colors.text` or `colors.highlight` as a background (they turn dark in light mode).
- Sidebar icons are two sets of the same drawings. A change to a nav icon changes both sets. Recorded in CHG-0160, marked provisional.
- The owner's 500-icon pack (`~/Downloads/guildmaster-500-icons-both-themes`, flat Font Awesome glyphs, CC BY 4.0) was reviewed and not used. Using it would need an attribution.
