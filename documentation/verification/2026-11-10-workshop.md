### C2 to C4: the running app

- **Check:** `serve.ts.txt` (the service on the fake harness) and `drive.py` (opens the Workshop from the rail, probes the page text, presses Limits and Accounts at 1440 by 900).
- **Found by driving, then fixed:** the card titles broke away from their red chip when long (the header wrapped as one unit), and the side-quest toggle overran the Send card's right edge. The header's left group now shrinks on its own and the toggle moved into the card's body; the screenshots are of the fixed build.
- **Weak probe:** `SELECTED []` in `drive.py` reads `aria-selected`, which the menu does not set (it sets the accessibility state `selected`); C3 rests on the screenshots.

## Reproduce

```sh
bun run typecheck && bun run check && bun run test
```

The window drive: copy `serve.ts.txt` to `packages/service/scratch-serve.ts` and run `GILD_DATA_DIR=/tmp/gild-ws ELECTRON_RUN_AS_NODE=1 ../../node_modules/.bin/electron scratch-serve.ts > /tmp/gild-serve.log` from `packages/service`; export the app (`cd apps/app && bunx expo export --platform web --output-dir /tmp/gild-export`) and serve it with `python3 -m http.server 8099` in that folder; then `python3 documentation/verification/2026-11-10-workshop/drive.py <existing output folder>`. Remove the scratch file afterwards.
