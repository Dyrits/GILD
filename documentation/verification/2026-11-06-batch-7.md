## Implementation choices not expressly settled by the agreement

- A deletion preview covers exact thread identifiers and active-turn counts. If they change before confirmation, the service asks for a new preview. Active turns include turns waiting for approval.
- Messages already received by surviving threads remain in those receivers' histories, with the erased sender's saved title. Messages addressed to erased threads are erased. Cached outcomes referring to erased threads or messages are removed.
- The threshold-triggering message is kept undelivered, together with subsequent messages. Continue delivers kept messages without replaying messages already accepted by a cancelled turn.
- An owner message or result resets a count but does not silently resolve an existing pause. The explicit decision still applies. Decisions identify one pause, so an old decision cannot resolve a later pause.
- Folding keeps owner-opened descendants visible beneath the nearest visible ancestor. Selecting an opener unfolds its hidden descendants at every depth; Attention and Failed threads remain visible independently.
- Workspace protection takes precedence when a scratch folder overlaps a registered workspace, including through an alias. In that exceptional case the overlapping scratch folder is retained while the mission's records are deleted.
