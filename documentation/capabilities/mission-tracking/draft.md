# Deferred capability specification

The [left navigation structure](specifications.md#left-navigation-structure) is specified under CHG-0134 through CHG-0137.
The following work is deferred and does not block that navigation agreement.

## Reserves screen

The owner deferred further screen specification until work on Reserves begins (CHG-0137).
Retain the [agreed usage direction](../budget-control/specifications.md#reserves-usage-page), including counts and local date boundaries; settle remaining screen interactions and acceptance then.
Proposal for that future specification: empty periods show no recorded usage; periods with records but no known usage show unavailable values and data-quality notices.

## Related capability work

Library is agreed as the home for generated and uploaded artifacts, especially without a workspace.
Its collection rules and lifecycle need their own specification; navigation does not imply copying every workspace file or preserving artifacts after quest deletion.
Workshop initially names MCP servers, connectors, and skills; further categories and connector operations need their own agreements.
Craft's navigation destination is agreed, but workflow execution and the behavior of a destination before that capability is available remain unspecified.
Empty groups and long labels must remain navigable; the precise presentation can be judged with the existing compact-navigation human acceptance.
