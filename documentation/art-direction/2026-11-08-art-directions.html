Canopy — four art directions

Each direction redraws the same two screens that currently use rows of chips: the harness, model, and effort defaults, and the approvals filter (scope and state). The common rule: chips only for a handful of short, frequently toggled choices; a picker for anything longer or rarely changed; and filters collapsed into one control with the active ones shown.

A · Quiet Native

Leans on OpenBot: keeps today's palette and blue accent; reads like macOS System Settings.
  • Segmented control for 2–3 options (harness); pop-up menu for the rest (model, effort).
  • Settings as grouped label/value rows, so the eye scans down one column.
  • Filters: one search field + a “Filter” menu; active filters appear as removable tokens.

B · Workbench

Leans on Delta (Zed lineage): a dark, dense developer tool with monospaced detail and keyboard hints.
  • Settings as a property inspector: one row per setting, the value opens a menu inline.
  • Effort shown as a 5-step meter instead of five words.
  • Filters typed as a query (scope:workspace state:active) with autocomplete.

C · Mission Board

Leans on intentic: warm paper tones, work laid out by what needs you; state becomes layout, not a filter.
  • State filter removed: Attention / Active / Finished are columns. Scope becomes a breadcrumb.
  • Cards carry model, branch, cost, and diff stats.
  • Settings use labelled selects with a hint, and effort as a slider with five stops.

D · Command-first

A blend: OpenBot's calm surfaces, Delta's keyboard speed, intentic's attention-first ordering; very little chrome.
  • Harness, model, and effort read as one sentence in the composer: “Claude Code · Fable · high”. Clicking or ⌘K opens a searchable palette.
  • Lists get saved views as tabs (Needs me, Active, All) with one “Filter” button for the rest.
  • Settings page keeps only defaults, shown the same way.
