# Start a new codebase and cherry-pick from MausBot and Paseo

A code review of MausBot (version 0.1.140) found about 530,000 lines of server code where the bot is the primary key of the store, routines, skills, memory, approvals, and UI, and no thread can exist without a bot; reshaping it into missions and threads would cost more than building them. We start a new codebase and cherry-pick well-tested plumbing under Apache 2.0, carrying each source's NOTICE attributions: from MausBot, the runtime event and driver contracts, the ACP client and vendor adapters, the protocol handling of its Claude Code and Codex drivers, the delegation-tree state machine (re-keyed from bot to thread), and the process and recovery helpers; from Paseo, the relay Worker and its encryption. Nothing comes from MausBot's `enterprise/` folder, its brand, or OpenBot, whose PolyForm Noncommercial license cannot become open source.
