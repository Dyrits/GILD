# Provider accounts are harness configuration folders

An account added in OpenMission is a folder the harness's own tool uses as its configuration home (`CLAUDE_CONFIG_DIR`, `CODEX_HOME`, `XDG_DATA_HOME` for OpenCode), signed in through the tool's own sign-in in a terminal window. OpenMission keeps the folder's path and a name, never a credential, so it meets "Comply with provider terms" while letting one computer run several subscriptions of one harness side by side. OpenBot keeps extra Claude accounts the same way (one configuration folder per account, seen in its data folder on 2026-11-07); no code was taken. The cost: an account's conversations live in its folder, so a thread cannot move to another account without a handover, and removing an account removes its threads' conversations, which is why removal waits until their missions end.
